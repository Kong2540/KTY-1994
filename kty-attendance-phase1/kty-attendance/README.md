# KTY1994 ระบบเช็คชื่อพนักงาน — คู่มือติดตั้งช่วงที่ 1

ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `01_schema.sql` | สร้างตาราง สิทธิ์ และบันทึกการแก้ไขใน Supabase |
| `index.html` | ตัวเว็บแอปทั้งหมด |
| `manifest.json`, `icon-192.png`, `icon-512.png` | ทำให้ติดตั้งเป็นไอคอนบนมือถือได้ |

## ขั้นที่ 1 สร้างโปรเจกต์ Supabase

1. สมัครที่ supabase.com แล้วกด **New project**
2. ตั้งชื่อ เช่น `kty-attendance` เลือก Region **Southeast Asia (Singapore)** ตั้งรหัสผ่านฐานข้อมูลแล้วจดเก็บไว้
3. รอประมาณ 1–2 นาทีจนโปรเจกต์พร้อม

## ขั้นที่ 2 สร้างฐานข้อมูล

1. เมนูซ้าย **SQL Editor** > **New query**
2. เปิดไฟล์ `01_schema.sql` คัดลอกทั้งหมดไปวาง แล้วกด **Run**
3. ต้องขึ้น `Success. No rows returned` ถ้ามี error ให้ส่งข้อความ error มาให้ผมดู

## ขั้นที่ 3 ตั้งค่าการ login

เมนู **Authentication** > **Sign In / Providers** > **Email**

- **Confirm email** ถ้าเปิดไว้ ผู้สมัครต้องกดลิงก์ยืนยันในอีเมลก่อน ถ้าปิด สมัครแล้วเข้าหน้า "รออนุมัติ" ได้ทันที เนื่องจากแอดมินต้องอนุมัติทุกคนอยู่แล้ว ปิดไว้ก็ปลอดภัยและสะดวกกว่า

เมนู **Authentication** > **URL Configuration**

- **Site URL** ใส่ที่อยู่เว็บจริงหลังทำขั้นที่ 5 (เช่น `https://kty1994.netlify.app`) ใช้สำหรับลิงก์ยืนยันอีเมลและลิงก์ลืมรหัสผ่าน

## ขั้นที่ 4 ใส่ค่าการเชื่อมต่อใน index.html

1. เมนู **Project Settings** > **API** (หรือ **Data API / API Keys**)
2. คัดลอก **Project URL** และ **anon public key**
3. เปิด `index.html` ด้วย Notepad หรือ VS Code ค้นหาบรรทัดนี้แล้วแทนค่า

```js
const SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
const SUPABASE_ANON_KEY = 'YOUR-ANON-KEY';
```

anon key เปิดเผยในหน้าเว็บได้ เพราะสิทธิ์ทั้งหมดถูกคุมด้วย RLS ในฐานข้อมูล แต่ **ห้ามนำ service_role key มาใส่ในไฟล์นี้เด็ดขาด**

## ขั้นที่ 5 นำเว็บขึ้นออนไลน์

วิธีที่ง่ายที่สุดคือ **Netlify Drop** (app.netlify.com/drop) ลากโฟลเดอร์ทั้งโฟลเดอร์ไปวาง จะได้ลิงก์ https ทันที หรือใช้ GitHub Pages ก็ได้

ต้องเป็น https เท่านั้น มือถือจึงจะติดตั้งเป็นแอปได้

## ขั้นที่ 6 ตั้งบัญชีแอดมินคนแรก

1. เปิดเว็บ กด **สมัครใช้งาน** ด้วยอีเมลของคุณกอง
2. กลับไป Supabase > SQL Editor รันคำสั่งนี้ (แก้อีเมลให้ตรง)

```sql
update public.profiles set role = 'admin' where email = 'อีเมลของคุณ@gmail.com';
```

3. กลับมาที่เว็บ กด **ตรวจสอบอีกครั้ง** จะเข้าหน้าหลักในสิทธิ์แอดมิน

หลังจากนี้ผู้สมัครคนอื่นอนุมัติผ่านหน้าเว็บเมนู **ผู้ใช้ระบบ** ได้เลย ไม่ต้องใช้ SQL อีก

## ขั้นที่ 7 ติดตั้งบนมือถือ

- **iPhone/iPad** เปิดลิงก์ใน Safari > ปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**
- **Android** เปิดใน Chrome > เมนู ⋮ > **ติดตั้งแอป** หรือ **เพิ่มไปยังหน้าจอหลัก**

## รายการทดสอบช่วงที่ 1

1. สมัครบัญชีที่สองด้วยอีเมลอื่น ต้องติดหน้า "รออนุมัติ"
2. แอดมินอนุมัติเป็น **โฟร์แมน/วิศวกร** และติ๊กไซต์ที่รับผิดชอบ บัญชีนั้นต้องไม่เห็นเมนูพนักงาน
3. เพิ่มพนักงาน ลองกรอกเลขบัตรผิดหนึ่งหลัก ระบบต้องเตือน
4. ใส่วันเกิดเป็น พ.ศ. อายุต้องคำนวณขึ้นทันที
5. แก้ค่าแรงพนักงาน ต้องถูกบังคับให้ใส่เหตุผล แล้วกด "ดูประวัติการแก้ไข" ต้องเห็นค่าเดิม ค่าใหม่ และเหตุผล
6. ปิดเน็ตมือถือ ต้องขึ้นหน้าแจ้งว่าออฟไลน์

## หมายเหตุ

- แพ็กเกจฟรีของ Supabase อาจหยุดโปรเจกต์ชั่วคราวถ้าไม่มีการใช้งานต่อเนื่องราว 1 สัปดาห์ (ตามนโยบายปัจจุบันของ Supabase) เมื่อใช้เช็คชื่อทุกวันจะไม่เกิดปัญหานี้
- การเปลี่ยนสิทธิ์ผู้ใช้ทำได้เฉพาะแอดมิน และระบบไม่ยอมให้ลดสิทธิ์แอดมินคนสุดท้าย
- ทุกการเพิ่ม/แก้/ลบ พนักงาน ผู้ใช้ ตำแหน่ง และไซต์ จะถูกบันทึกในตาราง `audit_log` ซึ่งไม่มีใครแก้หรือลบได้จากหน้าเว็บ
